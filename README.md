# Library door

Personal-use GitHub Pages door for a private library.

- This repository does **not** contain videos, cookies, or the library files.
- The page is password-gated (AES-GCM). After unlock it only reveals a private
  path to the live library on the home LAN or Tailscale network.
- Playback still requires the machine that hosts the library; off-LAN access
  still needs Tailscale (the live library URLs themselves have no password).
- The password is stored only on the host machine, not in this repo.

Pages URL: https://algowise-ai.github.io/media-library/
